    ONBOARDING · LOCAL FIRST

    Try Browser Tracker

    Four short steps to connect your own browsing totals to the dashboard above.

    1. 01

      Add the extension

      Browser Tracker is still in development, so it is not published in an extension store yet. A website cannot install an unpacked extension for you — you add it yourself from the project folder. That is a deliberate browser safety rule, not a missing feature.

    2. 02

      Load it in your browser

      Open your browser’s extensions page, switch on Developer mode, choose Load unpacked, and select the project’s extension/ folder.

      • Opera GX: go to opera://extensions.
      • Chrome: go to chrome://extensions.

      The extension works in Chromium-based browsers only. Firefox and Safari are not supported.

    3. 03

      Enable portfolio sharing

      Open the extension from the toolbar’s extensions menu, then switch Share with portfolio to On. You can also find the same setting in the extension’s options page.

      Sharing is off by default. Nothing reaches this dashboard until you explicitly enable it, and you can disable it again at any time.

    4. 04

      Explore your dashboard

      Come back to the Browser Tracker dashboard and keep this tab open. Your own active time, open tabs, most-used websites, and seven-day activity appear automatically once the extension is installed, enabled, and connected.
