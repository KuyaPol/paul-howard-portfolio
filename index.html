SOURCE-VERIFIED / CONCEPT / LAB RECORD

Browser Tracker

Outcome

A local-first activity dashboard paired with a Manifest V3 browser extension and a Python desktop interface. It reports only your own activity when sharing is enabled.

Stack

JavaScript for the extension, Python for the local interface, and a local data path.

Privacy model

The dashboard remains empty until a local extension is connected and sharing is explicitly enabled. No visitor statistics are invented in this portfolio.

Status

Local tool record. Not a hosted service and not a completed public product.
