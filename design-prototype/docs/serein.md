# P—04 / SEREIN — proposal notes

**Status:** Project proposal / planned. SEREIN is a proposed personal Windows 11 desktop AI assistant by Paul Howard Chavez, BSIT Student & Aspiring Software Developer. This repository does not contain a completed assistant, installer, public release, live AI conversation, microphone capture, screen capture, assistant memory store, or Windows automation implementation.

## Published proposal

The authoritative document is `../assets/docs/SEREIN_Full_Project_Proposal_Paul_Howard_Chavez.pdf`. In production the same file is copied into `public/assets/docs/` by `build.mjs` and published at `/paul-howard-portfolio/assets/docs/SEREIN_Full_Project_Proposal_Paul_Howard_Chavez.pdf`.

The PDF must be supplied as a real, nonempty, readable file. It is not generated or replaced by this repository. The project entry, destination page, and PDF itself preserve the author attribution.

## Stated design intent

- Natural voice conversations.
- User-controlled screen awareness.
- Local memory.
- Permission-based desktop automation.
- Local Windows functionality combined with cloud-assisted AI reasoning.
- Privacy, reliability, and low resource usage as stated priorities.

These are proposal goals, not implemented or measured results.

## Planned technologies

Python, PySide6, Windows 11, SQLite, Windows UI Automation, Windows Graphics Capture, Cloud AI APIs, and voice recognition/synthesis are named as planned technologies. Their presence in the proposal does not mean that any library, API, or Windows capability has been integrated.
