# Hero network sphere — direction contract

Scope: `design-prototype/index.html` hero and its shared WebGL scene. Mode: Experience (the artifact leads). Audience: visitors scanning a technical portfolio who need the signal/systems idea to register before they read the copy.

THESIS: The hero proves a living system rather than showing a globe. The sphere is an irregular 88-node mesh with visible rear depth, local highlights, and travelling data; it replaces the Earth as the first thing the visitor reads.

OWN-WORLD: Near-black graphite ground, electric cyan as the structural signal, restrained lime as emphasis, muted neutral grey for secondary paths. Thin luminous linework, small hard node cores, soft atmospheric halos, Syne/Manrope type, compact mono labels, and a fixed grid shell stay unchanged.

STORY: A visitor sees a self-organising practice — many small nodes, selective links, and pulses moving through the structure — then reads the short positioning line and chooses Explore Work or View Profile.

FIRST VIEWPORT: Left third holds the eyebrow, oversized two-line heading, one-line intro, and two actions. The sphere occupies roughly half the viewport width on the right, centered near 75% x / 54% y with controlled right-edge cropping. Rear connections stay visible; the copy remains readable without a panel.

FORM: Pinned by the user's written brief and supplied structural reference; no concept roll. `seed: none (pinned)`. “Replace the existing Earth/planet hero visual with a large, interactive 3D network sphere… use Signal / Systems palette… slow automatic rotation, smooth pointer tilt, direct drag rotation, inertia… mobile static representation.”

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

`2026-11-22`: Implemented and browser-verified. Provenance is recorded in `docs/hero-network-static-asset.md`; measurements are in `performance-phase12.json`; screenshots are listed in `README.md`. Visual verdict is still pending human review.
