A serious proposal for a private, user-controlled desktop assistant.

SEREIN is an official personal software project proposal by Paul Howard Chavez, a BSIT student and aspiring software developer. It is not a completed application, public release, installer, or working demonstration.

“SEREIN is a proposed lightweight Windows 11 AI assistant designed for natural voice conversations, user-controlled screen awareness, local memory, and permission-based desktop automation. The system will combine local Windows functionality with cloud-assisted AI reasoning, prioritizing privacy, reliability, and low resource usage.”

PROJECT IDENTITY

Personal Windows Desktop AI Assistant

A proposal for how a lightweight Windows 11 assistant could work, with explicit permission boundaries and local-first behavior.

DOCUMENT STATUS

Proposal, not release notes

The PDF documents planned architecture and development requirements. It does not verify completed capabilities.

The project is published here as the fourth declared personal software project, alongside Browser Tracker, Live Voice to Text, and Interactive Experiments. Those three projects keep their own source-verified, concept, and lab status labels.

02 / DEVELOPMENT STATUS

The proposal stage is explicit.

    No voice recognition, screen monitoring, local memory, or desktop automation is implemented in this portfolio repository.

  • NO INSTALLER

    No executable installer, application package, public download, or released desktop app is available from this project entry.

Any technology named on this page is a proposed technology. Names in the proposal do not mean a library, API, or Windows capability has already been integrated.

03 / PLANNED CAPABILITIES

Four capabilities the proposal sets out to explore.

PLANNED / 01

Natural voice conversation

The proposal describes spoken interaction as a goal. No speech engine or live conversation is implemented here.

PLANNED / 02

User-controlled screen awareness

Screen context would be opt-in and permission-based. No capture or monitoring is active on this site.

PLANNED / 03

Local memory

The design calls for local storage of user-controlled context. No assistant memory exists in this repository.

PLANNED / 04

Permission-based automation

Desktop actions would require explicit permission. No Windows control capability is implemented or demonstrated.

Privacy, reliability, and low resource use are stated design priorities in the proposal, not measured product results.
