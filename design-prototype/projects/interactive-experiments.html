A laboratory for techniques, not a single shipped product.

Interactive Experiments is the portfolio label for a set of small visual and interaction studies. Source inspection shows several of those techniques are genuinely implemented in the existing prototype: a shared Three.js scene renderer, crossfaded scenes, tiered quality controls, pointer-reactive parallax, travelling network pulses, scroll-linked motion, and procedural ambient visuals.

This page records those implementations and separates them from concepts. The three probes in the interactive lab below are newly developed for this deep-dive page. They use lightweight Canvas 2D and explain the same kinds of techniques without presenting themselves as a standalone product or reusing a second WebGL renderer.

PURPOSE

Make technique visible

Show how motion, procedural form, input mapping, and restraint are actually built in this prototype.

SCOPE

Record, not release

02 / PROBLEMS EXPLORED

How much interaction and motion can a portfolio carry before it costs the visitor?

The experiments cluster around five practical questions rather than a single product brief:

  • Depth without heaviness: how far a shared WebGL renderer can carry procedural scenes before a second renderer is justified.
  • Input mapping: how pointer, keyboard focus, and scene state can drive the same visual language.
  • Procedural form: how geometry, particles, bands, and pulses can be generated from small amounts of code and shared geometry.
  • Motion restraint: how animation can stop when a scene is hidden, an overlay is open, or the visitor prefers reduced motion.
  • Accessible experimentation: how a visual study can still expose keyboard-operable controls and textual explanations.

These are themes observed in the source and the lab record. They are not a funded research programme or measured product outcomes.

06 / ARCHITECTURE & MOTION

One existing renderer, one new lightweight bench.

Existing prototype renderer

The shared scene module builds each visual on demand, crossfades between them, and keeps a single animation loop. Desktop quality tiers adjust geometry and frame pacing; pointer parallax and focal shifts are eased. Networks use shared geometry and instanced meshes where practical, with pulses travelling along precomputed paths. Overlays pause rendering, and disposal removes listeners, geometries, materials, and framebuffers.

Lab bench loop

The new bench uses one 2D canvas and one selected experiment model. A resize observer keeps the drawing buffer at a capped device-pixel ratio; an intersection observer and the page visibility API stop the animation loop when the bench is off-screen or the tab is hidden. Reduced motion renders a static frame and disables the loop entirely. Tab switches rebuild only the selected model, so unused particle, graph, and wave state is not retained.

Network handoff

The P—03 node remains a real HTML button in the Project Network. Its activation uses the same highlight, camera-ease, fade, and delayed navigation path as P—01 and P—02. The destination is this dedicated page; the old Work-dialog URL redirects here.

07 / PERFORMANCE & ACCESSIBILITY

Restraint is part of the experiment.

  • No extra WebGL context: the lab uses Canvas 2D only. The existing network keeps its single shared renderer.
  • One active probe: only the selected experiment updates; the other two models are rebuilt on demand.
  • Bounded work: particle count scales with viewport area, node count is capped at 18, and device-pixel ratio is capped at 1.5.
  • Idle stop: the loop pauses off-screen, when the tab is hidden, when the visitor presses Pause, and under reduced motion.
  • Keyboard parity: tab buttons support Arrow, Home, and End; sliders and action buttons are native controls; all state changes are announced in a polite live region.
  • Focus and motion: the shared two-pixel focus outline is preserved, and reduced motion removes page, panel, and canvas motion.
  • Mobile: no WebGL renderer is created on small or coarse-pointer devices, and the lab canvas uses a compact aspect ratio.

These are implementation safeguards, not benchmark results. Phase 8 performance records remain the source for measured renderer metrics.

09 / LIMITATIONS

What this record does not claim.

  • No public, downloadable, or account-based Interactive Experiments application exists in this repository.
  • The lab probes are newly written explanatory Canvas 2D demos, not previously shipped portfolio features.
  • No audio input, microphone capture, speech analysis, model inference, or audio playback is part of the existing spectrum or this lab.
  • No save, export, share, replay, or experiment-gallery system is implemented.
  • No independent benchmark, cross-browser matrix, or accessibility audit is claimed for the new probes.
  • WebGL remains desktop-only in the existing prototype; mobile visitors receive the lightweight 2D fallback.
